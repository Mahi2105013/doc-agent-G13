| Stage | Problem statement | Data | Model | Methods | Design | Development | Deployment | MLOps |
|---|---|---|---|---|---|---|---|---|
| 0 Frame | Define the end-to-end multimodal document QA pipeline scope, performance targets, and system contracts. | Scanned Bengali document pages/PDFs and ground-truth text annotations. | None | Requirements analysis, contract schema definition (Page, Region, Chunk). | Modular pipeline architecture with standardized contract interfaces between stages. | Virtual environment setup, dependency management, repository layout. | CLI scripts and project structure initialization. | Version control (Git), project configuration management (`config.yaml`). |
| 1 Ingest+Enhance | Extract rasterized page images from PDFs and preprocess them to improve downstream OCR accuracy. | Scanned PDF files, intermediate image files (`data/raw/images`, `data/raw/preprocessed`). | PyMuPDF (`fitz`), OpenCV (`cv2`). | PDF rendering (150 DPI rasterization), grayscale conversion, filtering by target page ranges. | Modular page loading and preprocessing pipeline returning structured `Page` objects. | Local execution script with fallback paths for project-root resolution and page filtering. | Standardized directory outputs (`data/raw/preprocessed/`). | Reproducible image loading and error-tolerant directory handling. |
| 2 Layout | Detect and classify document regions (text, headers, footers, figures, tables) to extract clean bounding boxes. | Preprocessed document page images. | `hantian/yolo-doclaynet` (YOLOv8 fine-tuned on DocLayNet). | Computer vision object detection, region boundary extraction, header filtering. | Bounding box mapping to standardized `Region` contracts (`kind: text/table/figure/heading`). | HuggingFace Hub model downloading (`hf_hub_download`) and Ultralytics inference. | Embedded inference using lightweight target model (`yolov8n-doclaynet.pt`). | Model weights caching via Hugging Face Hub integration. |
| 3 OCR | Transcribe Bengali text within extracted page regions accurately into machine-readable text. | Cropped image regions, Tesseract `.traineddata` models, ground-truth text evaluation labels. | Fine-tuned Tesseract OCR (`ben_seerah.traineddata`). | Optical Character Recognition, bounding box cropping, PSM 6 page segmentation layout handling. | Dedicated `Reader` class querying region crops and mapping outputs to structured `Chunk` objects. | PyTesseract integration with custom `TESSDATA_PREFIX` environment path resolution. | Packaged local traineddata deployment in `src/doc_agent/models/`. | Token-level F1, Precision, and Recall evaluation benchmarking. |
| 4 Index | Convert text chunks into dense vector embeddings and build a searchable index for vector retrieval. | Extracted text chunks (`Chunk` objects), embedding matrices, vector index artifacts. | `sentence-transformers/all-MiniLM-L6-v2` (with HuggingFace Transformers & n-gram hash fallbacks), FAISS. | Recursive character text splitting (size 500, overlap 50), dense vector encoding, FAISS Indexing (Flat, IVF, HNSW). | Two-step pipeline: overlapping chunk splitter -> embedding encoder -> FAISS index store & metadata pickling. | Fallback mechanisms for offline/CI embedding generation and dynamic FAISS index type selection. | Persisted local vector store files (`index.faiss`, `vectors.npy`, `chunks.pkl`). | Deterministic hashing fallbacks for offline testing and training size safety guards. |
